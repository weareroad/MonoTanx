# Game audio

Sounds are loaded by `GameAudio` from this folder through the MonoGame content pipeline (`../Content.mgcb`). See `docs/audio-spec.md` for the design.

| File | Used for |
|---|---|
| `fire.wav` | A tank fires a shell (Player 2 plays it at a different pitch) |
| `reload.wav` | A tank's reload has finished |
| `explosion.wav` | A shell hits a tank |
| `ping.wav` | A shell reflects off a reflective surface |
| `crump.wav` | A shell hits a solid, non-reflective surface |
| `pickup.wav` | A tank collects a pickup |
| `engine.wav` | Engine drone, looped (one second, whole cycles so it loops cleanly) |

## Current files are placeholders

They are synthetic sounds made by `tools/generate_placeholder_audio.py` (deterministic: running it again gives identical files), so there are no licensing questions. Regenerate them with:

```sh
python3 tools/generate_placeholder_audio.py
```

## Replacing a placeholder with a real sound

1. Save the new sound as a **16-bit PCM WAV** (mono or stereo, 44.1 kHz recommended) with the **same file name**, replacing the existing file. Other formats such as MP3 and OGG would need `ffmpeg` at build time, so use WAV.
2. No code or `Content.mgcb` change is needed.
3. Record where it came from and its licence in the table below.
4. Run `dotnet test`: `AudioAssetTests` check each file is a valid 16-bit PCM WAV with a pipeline entry.
5. Adjust the volume in `Tuning.Audio` if the new sound is louder or quieter than the placeholder.

Do not run the generator after replacing files, as it overwrites them.
